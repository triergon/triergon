# D4 evidence (small files)

Raw TIME/MEM records and the combined functional gate's full output (including its extracted
test assets, whose rights are unreviewed) live outside git in
`.research/m1d4/evidence/d4-results/` (`time-D1`, `mem-D1`, `time-D2`, `mem-D2`,
`functional-combined-D1-2`, `functional-combined-D2`, and the invalid/startup-failed gate runs).
`D1/*.sha256` and `D2/*.sha256` list every file of those directories with its hash. Kept here:
ledgers, identity hashes, correctness JSONL and summaries, gate summaries and MEM lifecycle
records. Binaries: `.research/m1d4/evidence/d4-bin/`.
