Generated from FreeType 2.15.0's source files by `cargo xtask fonts tables`:

| Module | FreeType source |
| --- | --- |
| `autofit/tables.rs` | `autofit/afscript.h`, `afstyles.h`, `afranges.c`, `afblue.h`, `afblue.c` (the latin and CJK blue strings), `afadjust.h`, `afadjust.c` |
| `postscript/tables.rs` | `psnames/pstables.h`; the standard and expert charsets and encodings of `cff/cffload.c` |

`cmap.rs`, `glyf.rs`, `kern.rs`, `lib.rs`, `metrics.rs`, `name.rs`, `outline.rs` and the
rest of `sfnt.rs` read the font formats and reproduce FreeType's reading of them, including its
repairs of malformed data; where their comments name a FreeType function, the code follows
it.

Following libass 0.17.5: the face scoring of `matching.rs`, the choice of synthetic styles
in `synthesis.rs`, the size request and load flags of `sized.rs`, and the text charmap
selection and lookup in `cmap.rs` and `lib.rs`.

Following HarfBuzz 14.6.0: the binary search in `read.rs` and the variation sequence
lookup in `cmap.rs`.

## triergon-shape

Translated from HarfBuzz 14.6.0: every module outside `bidi/` and `unicode/bidi/`. That is
the shaping pipeline (`shape.rs`, `plan.rs`, `buffer.rs`, `normalize.rs`, `fallback.rs`,
`props.rs`, `face.rs`, `work.rs`, `tag.rs`), the layout tables (`ot/`), the script
shapers (`shapers/`), the language tags (`language/`), the `cmap` reading of HarfBuzz's
built-in font functions (`cmap/`), the Unicode functions (`unicode/`), and the built-in
font functions in `metrics.rs`.

Generated by `cargo xtask shape ucd` from HarfBuzz 14.6.0's source files, together with
Unicode data: `language/tables.rs`, `cmap/tables.rs`, `unicode/tables.rs` and
`unicode/syllabic_tables.rs`.

Following libass 0.17.5: the font functions libass installs on a sized face
(`SizedMetrics` in `metrics.rs`, from `ass_shaper.c`) and the rotation decisions of its
glyph metrics cache (`rotations.rs`).

`bidi/` is written from UAX #9 with the Unicode C reference implementation as its model,
and `unicode/bidi/tables.rs` is generated from the Unicode Character Database;
[crates/shape/THIRD-PARTY.md](../crates/shape/THIRD-PARTY.md) records both.
